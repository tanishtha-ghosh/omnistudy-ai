# OmniStudy AI 📚

An AI-powered Smart Learning Companion that helps students upload notes, chat with PDFs using RAG, generate summaries, quizzes, flashcards, and personalized study plans.

## Features

-  PDF Upload
-  AI Chat with Notes (RAG)
-  AI Summaries
-  Flashcards
-  Quiz Generation
-  AI Study Planner
-  Dashboard Analytics

## Tech Stack

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- FastAPI
- Python

### AI
- Google Gemini
- PyMuPDF
- Retrieval Augmented Generation (RAG)

## Installation

git clone https://github.com/tanishtha-ghosh/omnistudy-ai.git

cd omnistudy-ai

pip install -r requirements.txt

python -m uvicorn backend.main:app --reload
